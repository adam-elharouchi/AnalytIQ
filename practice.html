Exercise 1: Basic Statistics

Easy

Calculate mean, median, and mode for a given dataset. Practice fundamental statistical calculations.

Solution:

import numpy as np

data = [10, 20, 30, 40, 50, 30, 30]
mean = np.mean(data)
median = np.median(data)
mode = max(set(data), key=data.count)

print(f"Mean: {mean}")
print(f"Median: {median}")
print(f"Mode: {mode}")

Exercise 2: Data Cleaning

Medium

Clean a dataset with missing values and outliers. Apply appropriate techniques to handle data quality issues.

Solution:

import pandas as pd

# Load data
df = pd.read_csv('data.csv')

# Handle missing values
df = df.fillna(df.mean())

# Remove outliers using IQR method
Q1 = df.quantile(0.25)
Q3 = df.quantile(0.75)
IQR = Q3 - Q1
df = df[~((df < (Q1 - 1.5 * IQR)) | (df > (Q3 + 1.5 * IQR))).any(axis=1)]

Exercise 3: Data Visualization

Medium

Create visualizations for sales data. Practice creating bar charts, line graphs, and pie charts.

Solution:

import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv('sales.csv')

# Bar chart
plt.bar(df['Month'], df['Sales'])
plt.title('Monthly Sales')
plt.xlabel('Month')
plt.ylabel('Sales')
plt.show()

# Line chart
plt.plot(df['Month'], df['Sales'])
plt.title('Sales Trend')
plt.show()

Exercise 4: Correlation Analysis

Hard

Analyze correlations between variables in a dataset. Identify relationships and create correlation matrices.

Solution:

import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

df = pd.read_csv('data.csv')

# Calculate correlation matrix
correlation_matrix = df.corr()

# Visualize correlation matrix
sns.heatmap(correlation_matrix, annot=True, cmap='coolwarm')
plt.title('Correlation Matrix')
plt.show()

Exercise 5: Time Series Analysis

Hard

Analyze time series data and identify trends. Practice forecasting and seasonal decomposition.

Solution:

import pandas as pd
from statsmodels.tsa.seasonal import seasonal_decompose

df = pd.read_csv('timeseries.csv', parse_dates=['Date'], index_col='Date')

# Decompose time series
decomposition = seasonal_decompose(df['Value'], model='additive')
decomposition.plot()
plt.show()
