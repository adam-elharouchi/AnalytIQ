# Chat & Conversation Sources

Place exported chat logs or conversation notes here to include them in the knowledge base.

## How to use

1. Export conversations from Cursor (or copy-paste important insights) into `.md` or `.txt` files
2. Save them in this `sources/` folder
3. Run the knowledge base generator:

   ```bash
   python3 scripts/generate_knowledge_base.py
   ```

The script will process these files and incorporate them into the appropriate topic categories.
