# Practice Playground & AI

The **Practice Playground** (`practice-playground.html`) is an interactive coding environment where students solve Python challenges with the help of an AI assistant.

## 🎮 Playground Features

### Code Editor
*   **Syntax Highlighting**: Supports Python syntax.
*   **Line Numbers**: Auto-syncing line numbers for better readability.
*   **Execution**: Code is executed securely (implementation detail: currently client-side or sandboxed backend).

### Exercise System
*   **Difficulty Levels**: Easy (Green), Medium (Yellow), Hard (Red).
*   **Timer & Accuracy**: Tracks time taken and solution accuracy.
*   **Stats**: Displays real-time performance metrics.

---

## 🤖 AI Code Assistant

### Integration
AnalytIQ integrates **Google Gemini** models to provide intelligent assistance.

### Capabilities
*   **Hint Generation**: Provides guided hints without revealing the full solution.
*   **Code Explanation**: Explains complex logic or error messages.
*   **Debugging**: Helps identify syntax errors or logical bugs.

### Context Awareness
The AI agent is aware of the current exercise context, allowing it to give relevant and specific advice.

---

## 🔄 Workflow
1.  Student opens an exercise from the **Student Portal**.
2.  Reads the problem description and difficulty.
3.  Writes code in the editor.
4.  Can ask the **AI Assistant** for help if stuck.
5.  Submits solution for verification.
