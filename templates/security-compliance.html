AnalytIQ Security and Compliance Overview

For Universities & IT Teams

1. Infrastructure Security

AnalytIQ is hosted on secure cloud infrastructure operated by AWS through Supabase in the United States (AWS US West region).

All data is stored in encrypted databases with controlled access.

2. Data Encryption

All data is protected using:

  • Encryption in transit using HTTPS/TLS
  • Encryption at rest using secure database encryption

3. Access Controls

AnalytIQ uses role-based access controls to ensure:

  • Students can only access their own data
  • Instructors can access only their classes
  • Administrative access is restricted and monitored

4. Authentication and Security

User authentication includes:

  • Secure password hashing
  • Session security protections
  • Access token controls

5. FERPA Compliance Measures

AnalytIQ:

  • Acts as a "school official" under FERPA
  • Processes student data only under institutional direction
  • Does not use student data for marketing or AI training

6. AI Data Protection

AI features:

  • Do not store or retain student prompts
  • Do not use student data to train models
  • Process data temporarily for real-time assistance

7. Data Retention and Deletion

Institutions control data retention policies.

Upon request or termination, institutional data can be deleted or returned.

8. Subprocessors

AnalytIQ uses trusted subprocessors including:

  • AWS cloud infrastructure via Supabase
  • AI processing services for real-time assistance

All subprocessors comply with industry security standards.

9. Incident Response

AnalytIQ maintains procedures to:

  • Detect unauthorized access
  • Investigate security incidents
  • Notify affected institutions where required

10. International Compliance Alignment

AnalytIQ aligns with:

  • FERPA (U.S.)
  • UK GDPR processor obligations
  • UAE PDPL data transfer requirements
