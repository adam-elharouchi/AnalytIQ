### What's included

- One class license: auto-graded practice exercises generated from the professor's own uploaded
  course materials (slides, readings, syllabus), locked to that course's actual content — not a
  generic problem set.
- A professor dashboard showing where the class is struggling, at the class and exercise level.
- LMS integration via LTI 1.3 (Canvas or Moodle) — students access AnalytIQ through the course
  tools they already use; no separate login.
- Coverage for one section, one semester.

### What's not included (out of scope for this order form)

- Multi-section or department-wide licensing — a separate conversation and a separate agreement.
- Custom integrations beyond the standard LTI 1.3 launch.
- Any commitment beyond the single term stated above; renewal is a new order.
